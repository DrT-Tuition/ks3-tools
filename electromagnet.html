Rule card

More turns and more current make an electromagnet stronger. Only a magnetic core (iron) helps. An iron core stops being a magnet when the current stops. A steel core keeps its magnetism. For a fair test, change one thing at a time.

Variables key

Change one variable (for example the turns). Measure the clips. Keep the rest the same (current and core).

Model limits: the clip counts come from one set of sample results and real results vary. Each loop drawn stands for 5 turns. Current is shown as low, medium or high, not in amps. Real electromagnets also heat up.

Remember: an electromagnet is a magnet only while a current flows. More turns and more current make it stronger. Only a magnetic core helps. Iron switches off. Steel keeps its magnetism. In a fair test you change one thing.
