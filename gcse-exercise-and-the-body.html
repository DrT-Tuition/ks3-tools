Metabolism is the sum of all the reactions in a cell or the body. Energy from respiration drives these reactions.

Model limits: No numbers are shown: real values differ from person to person, so the meters only show which way each one changes compared with rest. Time is speeded up, and the model pauses when nothing is changing. Here, jogging is set so that the oxygen supply keeps up and sprinting so that it doesn’t; in real life this depends on the person. Energy bars only show “much less”, not exact amounts. Particles stand for “some lactic acid”, not real molecules. The body is simplified and not to scale.
