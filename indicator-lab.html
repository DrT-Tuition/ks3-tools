Your pH scale

Model limits: Real indicator colours vary a little. Litmus only shows acid or alkali, never a pH number. Real red cabbage shows more colours than the three here. An indicator only shows what is already there: it doesn't change the solution. Solutions 1–6 have pH values set by the model. Named substances show only acid, neutral or alkali here: every named acid shows one colour and every named alkali another, because their real pH values vary. A colour never tells you that something is safe. Never taste or touch chemicals in the lab.

    Colour key: what each colour means

    Blue litmus: turns red → acid. Stays blue → neutral or alkali.

    Red litmus: turns blue → alkali. Stays red → acid or neutral.

    Red cabbage: red → acid. Purple → neutral. Green-yellow → alkali.

    Universal indicator: below pH 7 (red, orange, yellow) → acid. pH 7 (green) → neutral. Above pH 7 (blue, purple) → alkali. The further from 7, the stronger.
