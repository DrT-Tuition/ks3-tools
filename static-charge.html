Rule card

Like charges repel. Unlike charges attract. Only electrons move. A charged object has an electric field: the space where its force acts. A neutral object has none. More + than − is positive; more − than + is negative; equal is neutral.

Model limits: a real balloon has billions of billions of charges, and only a few are drawn. One rub moves one electron here so that you can count. In a real object the protons stay inside the atoms. Only charged balloons are shown pushing and pulling.

Remember: a charged object has an electric field: the space where its force acts. A neutral object has none. Only electrons move. Rubbing never makes charge. It moves electrons from one object to the other. Like charges repel. Unlike charges attract. A neutral object has + and − in equal numbers.
